# Publish this project to GitHub (GitHub Desktop — no terminal required)

This ZIP is a folder of **files**; uploading the ZIP as one file to a GitHub repository does **not** automatically display its contents as source code. Unzip it first.

## Steps

1. Install **GitHub Desktop** from https://desktop.github.com/ and sign in to your GitHub account.
2. Extract `USC-ITP380-GitHub-Ready.zip` on your computer.
3. Open the extracted folder `USC-ITP380-Game-Programming-Labs`. You should see `Lab01`, `Lab02`, ... `Lab12`, `Libraries`, `CMakeLists.txt`, and `README.md`. **This is the folder you should select**, not its containing folder.
4. In GitHub Desktop, go to **File → Add Local Repository… → Choose…** and select that folder.
5. Because this is a fresh import, Desktop may display **“This directory does not appear to be a Git repository.”** Select **“create a repository here”**. Give it a name such as `USC-ITP380-Game-Programming-Labs`; when prompted for extra README/license options, do not create new ones (a README already exists, and a license must not be assumed). Complete **Create Repository**.
6. If GitHub Desktop shows uncommitted changes, enter `Initial import of USC ITP 380 labs` in **Summary**, then click **Commit to main**. If it already made the initial commit, skip this step.
7. Click **Publish repository**. For now, **leave “Keep this code private” checked** until you have confirmed you are allowed to share the course framework and assets publicly.
8. Click **Publish Repository**. You can then use **Repository → View on GitHub** to open it in your browser.

## Before publishing publicly for your portfolio

- Check your USC course policy on publishing solutions and provided starter code, and check the rights to redistribute game media and third-party materials.
- Retain original authorship notices and do not claim that all source was written from scratch by you.
- Where possible, add a short section explaining your own engineering contributions and screenshots/gameplay clips.
- Don't add a license without considering original copyright and third-party licenses.

These steps follow GitHub's Desktop documentation: https://docs.github.com/en/desktop/adding-and-cloning-repositories/adding-a-repository-from-your-local-computer-to-github-desktop and https://docs.github.com/en/desktop/adding-and-cloning-repositories/adding-an-existing-project-to-github-using-github-desktop
